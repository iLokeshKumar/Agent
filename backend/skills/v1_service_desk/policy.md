# Policy: V1 Service Desk

## Request types
service_request · rma · warranty_claim · technical_support ·
complaint · amc_query

## SLA targets (first response)
| Type | Target |
|---|---|
| complaint | 15 min |
| rma / warranty_claim | 30 min |
| service_request | 60 min |
| technical_support | 2 h |
| amc_query | 4 h |

## Escalation
- Angry/negative sentiment → human handoff with full context bundle.
- Out-of-warranty repair → quote first, never proceed on assumption.
