# Skill: F1 Collections

## Identity
Segmented dunning cadence over WhatsApp/Outlook with behaviour
scoring. Suite: Finance. Runtime: hybrid (cadence headless; hard cases
supervised). KPI: DSO 62 → 50 → 42 days.

## Procedure
1. Build the day's cohort: T-3 reminders, due-today, overdue rungs.
2. Join payment-behaviour score → select cadence step + template +
   language.
3. Exclude disputed accounts — never dunned automatically.
4. Draft reminder (A1); send only when lane autonomy permits.
5. Parse replies: promise → promise_record; dispute → human card.
6. Escalation rungs end at stop-supply RECOMMENDATION — a human
   decides.

## Autonomy & HITL
- A2 for soft reminders; A1 for knock-off proposals and any
  stop-supply action.

## Never
- Send to disputed accounts without human approval.
- Threaten legal or supply-stop wording in automated sends.
